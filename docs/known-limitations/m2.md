# M2 Known Limitations

M2 is deterministic local-development sensor simulation, not a production farm or animal model.

- Temperature, relative humidity, and NH3 are simple independent bounded random walks. They are not
  scientifically calibrated farm trajectories, sensor specifications, veterinary thresholds, or
  statements about healthy or unhealthy conditions.
- There is no animal physiology, disease state, ground truth, feeding, drinking, weight, movement,
  behavior, camera, computer vision, RFID, thermal, tracking, fusion, anomaly, health score, alert,
  prediction, LLM, RAG, or real-hardware behavior.
- The three sensor streams are independent. They do not model correlated weather, ventilation,
  housing, control systems, sensor drift, calibration, failure, missing samples, or network delay.
- Generated runtime evidence is only `SYNTHETIC` + `LIVE`. Recorded simulator replay is not
  implemented; M1's existing `SYNTHETIC` + `RECORDED` contract fixtures remain unchanged.
- Simulator state is process-local and restarts from configuration. There is no state checkpoint,
  database-backed configuration, durable outbox, or exactly-once producer guarantee.
- A run repeated with the same seed, source ID, call order, and controlled timestamps intentionally
  recreates the same event IDs and envelopes. With PostgreSQL data retained, M1 treats those events
  as duplicates rather than new observations.
- M1's broker-to-database guarantee still begins only after the ingestion consumer's successful
  SUBACK. Starting the simulator before API readiness can lose broker-acknowledged observations.
- Graceful stop interrupts cadence waits immediately but lets an in-flight publication complete or
  exhaust the bounded M1 timeout/retry policy.
- The CLI and loopback Compose stack are local-development tools. Production MQTT authentication,
  TLS, authorization, edge buffering, deployment, retention, backup, and recovery remain undefined.
- The simulator has no container service because M2 does not yet justify another operated unit.
