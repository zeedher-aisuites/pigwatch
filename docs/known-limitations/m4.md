# M4 Known Limitations

M4 is a deterministic local-development spatial presentation, not a surveyed farm, production
digital twin, animal model, or clinical interpretation surface.

- The single development layout is compile-time frontend configuration. It has no persistent
  editor, commissioning flow, API, database representation, multi-site selection, survey accuracy,
  version negotiation, or shared/public schema guarantee.
- Only the existing `sim-temperature-1`, `sim-humidity-1`, and `sim-nh3-1` M2 sources have canonical
  placements. Loaded sources without placement remain visible in M3 and are counted in M4.
- Spatial coordinates describe the presentation only. They are not observation evidence,
  simulation ground truth, physical installation records, or inferred source location.
- The scene uses lightweight procedural geometry and intentionally has no remote models, textures,
  photorealistic assets, weather, workers, vehicles, or facility-control behavior.
- Desktop/laptop is the primary interactive 3D target. Tablet and narrow layouts retain the 3D
  region where supported, but the textual sensor directory is the authoritative accessible
  fallback. Formal 3D accessibility certification is not claimed.
- WebGL availability and context loss can depend on browser, driver, remote-desktop, power, and
  device policy. When unavailable, the 3D presentation is omitted without hiding telemetry.
- Telemetry is the newest bounded M1 API result and still uses M3 completion-scheduled polling,
  not streaming, cursor pagination, or complete history.
- A configured placement with no matching loaded source/payload observation shows `NO RECENT
  TELEMETRY`; M4 does not infer sensor failure or fabricate a value.
- M4 has no pigs, animal silhouettes, animal position or animation, tracking, cameras, video,
  computer vision, RFID, thermal data, sensor fusion, alerts, anomaly detection, health scoring,
  predictions, environmental danger thresholds, diagnosis, LLM, or paid service.
- Physical-sensor commissioning, production authentication/authorization, facility data ownership,
  spatial persistence, and deployment remain undefined.
