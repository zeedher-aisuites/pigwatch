# Active Execution Plans

Long-running or multi-stage work keeps an execution plan here while active. Name plans `YYYY-MM-DD-short-title.md` and include objective, scope, milestones, validation, risks, and current status. Move completed plans to `../completed/` without rewriting their history.

M0 is represented by the initiating task brief and repository history; no additional active plan remains after the foundation is validated.
