# PigWatch Telemetry

Reusable M1 observation decoding, MQTT transport, ingestion, PostgreSQL persistence, query and
structured logging. This package is infrastructure for source adapters; it does not implement a
sensor, simulator, anomaly model or product UI.

The normative behavior is defined in
[`docs/specs/m1-telemetry-core.md`](../../../docs/specs/m1-telemetry-core.md).
